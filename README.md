# MBTI 공부법 연구소

MBTI 네 기질 그룹(NT·NF·SJ·SP)별 공부법과 시험 전략을 정리한 정적 콘텐츠 사이트.

## 구성

| 파일 | 내용 |
|------|------|
| `index.html` | 서비스 소개 + 기질 그룹 카드 4개 + 자가진단 진입 |
| `nt.html` / `nf.html` / `sj.html` / `sp.html` | 그룹별 성향 설명 + 유형별 공부법 + 시험 꿀팁 |
| `test.html` + `test.js` | 공부 습관 10문항 자가진단 → 기질 점수 합산 → 그룹 판정 + 공유 |
| `style.css` | 공통 디자인 (크림 배경 + 보라 포인트 + Pretendard, 모바일 반응형) |
| `fonts/` | Pretendard 가변 폰트 (자체 호스팅) |

## 실행

빌드 과정 없음. 정적 파일이므로 `index.html`을 브라우저에서 열거나, 아무 정적 서버로 서빙하면 됩니다.

```
npx serve .
```

## 원칙

- 서버·API·외부 요청·키를 사용하지 않는다 (순수 정적 파일).
- 자가진단 입력값은 브라우저 안에서만 계산되며 저장·전송되지 않는다.
- 성격 유형은 참고용이며, 실제 공부법은 직접 실험해 조정하는 것을 전제로 한다.
